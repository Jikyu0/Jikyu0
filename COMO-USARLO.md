# Cómo instalar este perfil en GitHub

1. Entra a GitHub y crea un repositorio nuevo llamado exactamente **Jikyu0**.
2. Déjalo como **Public**.
3. Marca la opción **Add a README file**.
4. Dentro del repositorio, crea una carpeta llamada `assets`.
5. Sube `header.svg` dentro de `assets`.
6. Reemplaza el contenido del `README.md` creado por GitHub con el contenido del archivo `README.md` de este paquete.
7. Confirma los cambios con **Commit changes**.

GitHub reconocerá automáticamente el repositorio porque tiene el mismo nombre que tu usuario y mostrará el README en la parte superior de tu perfil.

## Antes de publicarlo

- Revisa que tu nombre y tu enlace de LinkedIn estén correctos.
- Cuando SECUB, RaizAR y HW Atelier tengan enlaces públicos disponibles, agrega el enlace correspondiente en el título o en un botón debajo de cada descripción.
- Puedes cambiar los colores del banner editando los tonos `#C6A7FF`, `#8D8CFF` y `#69D8FF` en `assets/header.svg`.
- No elimines la ruta `./assets/header.svg` del README; es la que carga la portada.
